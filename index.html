💡 About This Project

GenoView-InverseKinematics provides tools for character animation. It focuses on the math behind limb movement. This application helps you lock feet in place while moving character legs. It removes the need for manual frame adjustments. Animators use this to keep characters on the floor during walk cycles.

⚙️ How to Use the Software

Once you install the program, launch it from your desktop shortcut. The main window shows a menu on the left side. Use the File menu to load your existing character model. The software supports standard animation file formats.

After you load your model, click the IK button. This activates the math engine. You can select the foot joints in the viewer. Once selected, click the Lock button to keep the feet attached to the floor. Use the slider to adjust the stiffness of the leg joints. This creates a realistic bend in the knees.
